Free OSINT Tools Online

A free, searchable directory of browser-based OSINT (open source intelligence) tools. Find a tool, click it, and use it straight away. No install, no sign-up for this site.

Live site: https://vaibhavsinghdangi.github.io/searchosnit/

What you can find

About 50 tools in nine categories:

Frameworks and directories
Search engines and archives
Images and video (reverse image search, metadata, verification)
Usernames and email
Domains, IP and networks (WHOIS, DNS, certificates)
Devices and infrastructure
Maps, geolocation and tracking
Social media and people
Verification and fact-checking
Features
Instant search and category filters
Frosted-glass design with automatic light and dark themes
Works on phones and laptops
Fast: plain HTML, CSS and JavaScript, no frameworks
Security-minded: strict content security policy, no inline scripts, safe external links
Search-engine ready: structured data, FAQ, sitemap
Project files
File	Purpose
index.html	Main page and crawlable tool list
style.css	Glass design and layout
app.js	Tool data, search and filters
404.html	Page not found
sitemap.xml, robots.txt	Search engine files
Run it locally

Download the files and open index.html in any browser. No build step is needed.

Add or fix a tool

Tools are listed in the D array at the top of app.js. Each entry looks like this:

["Tool name", "https://example.com", "Short description", ""]

Use "login" as the last value if the tool needs an account. Open an issue or send a pull request, or email vaibhavsinghdangi34@gmail.com.
